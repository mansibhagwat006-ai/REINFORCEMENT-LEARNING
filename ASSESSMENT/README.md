## How to run

Open PowerShell/Command Prompt in this folder and run:

```text
python B_Task_1_Delivery_Reward_Function.py
python B_Task_2_Agent_State_Tracker.py
python B_Task_3_Action_Reward_Episode_Logger.py
python B_Task_4_Simple_RL_Environment_Simulator.py
python Section_C_Food_Delivery_RL_Concept_Simulator.py
python D_Original_AI_Code.py
python D_Corrected_Code.py
```

Section C is menu-driven:
1. Start New Delivery Episode
2. View Agent Stats
3. Exit

The assessment asks for screenshots of program output, so take screenshots after running the programs and include them with the submission.
